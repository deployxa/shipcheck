# Reproducible fixtures

All fixtures are synthetic, generated by `scripts/create_fixtures.sh`, and
committed to the repository so scans are reproducible byte-for-byte.
Symlinks pointing outside the `security-traps` fixture are recreated by the
same script (they cannot be represented in a zip/tarball portably).

| Fixture | Purpose | Expected outcome (documented contract) |
| --- | --- | --- |
| `healthy-node` | negative control: clean Node service with pinned base image, USER, exec-form CMD, HEALTHCHECK, declared env vars, SIGTERM handler | **zero findings** at any threshold |
| `broken-node` | positive: most rules fire (dev entrypoint, missing COPY target, latest base, shell CMD, curl&#124;sh, root, undeclared/unreferenced env vars, compose refs, privileged, host network, docker.sock, hardcoded ports, secrets, missing script file, floating dep, real .env) | 25 distinct rule IDs |
| `python-app` | Python stack: unpinned requirement, root container, declared-but-unused var, no signal handling | `SC-DEP-001`, `SC-DCK-002`, `SC-ENV-002`, `SC-GRD-001`; **no** `SC-ENV-001` |
| `compose-stack` | negative control: image-only compose stack with declared volumes, existing env_file, healthchecks | **zero findings** |
| `monorepo` | two Node applications in one repository | both apps discovered; monorepo ambiguity note; `SC-ENV-001` for the undeclared `API_PORT` |
| `fs-persist` | SQLite dependency + uploads path, no volumes | `SC-FS-001` present |
| `empty` | no manifests at all | only `SC-DIS-001` |
| `security-traps` | adversarial: escaping symlinks, 30-level deep tree, 6 MB file, binary file, malformed package.json/compose, lifecycle canary scripts | no crash; `SC-DIS-003`; scan marked incomplete; **canaries never created** (execution proof) |

## Regenerating

```console
make fixtures        # scripts/create_fixtures.sh + symlink re-creation
```

The fixtures are inputs to `internal/rules/rules_test.go`,
`internal/cli/cli_test.go` and `internal/discovery/discovery_test.go`, which
assert the expected-outcome column above. Changing a fixture requires
updating its documented contract in the same commit.

## Canary protocol

`security-traps/package.json` contains a `prepare` lifecycle script and a
`start` script that would `touch` canary files in the fixture directory and
in the system temp directory. `TestStaticModeNeverExecutesProjectCode` runs a
full scan and asserts the canaries do not exist. This is the documented
proof that static mode executes no project code.
